# プライバシーポリシー

**はかる - 案件ごとの作業時間を自動で記録**（以下「本拡張機能」）は、利用者のプライバシーを尊重し、個人情報を適切に取り扱います。本ポリシーでは、本拡張機能が取り扱う情報とその利用方法について説明します。

制定日：2026年11月14日
最終更新日：2026年11月14日

---

## 1. 収集・保存する情報

本拡張機能は、作業時間の記録に必要な以下の情報を **利用者のブラウザ内（`chrome.storage.local`）にのみ** 保存します。

| 情報 | 内容 |
|---|---|
| クライアント情報 | 利用者が入力したクライアント名、表示色 |
| 案件情報 | 利用者が入力した案件名、表示色、所属クライアント |
| 作業記録 | 作業の開始時刻・終了時刻、対象の案件 |
| 計測状態 | 現在計測中の記録、計測開始時刻 |
| 設定 | デフォルト案件、休憩判定までの時間、自動停止までの時間、ブラウザ起動時に自動で開くかどうか |

本拡張機能は、以下の情報を **収集しません**。

- 氏名、メールアドレス、住所などの個人を特定する情報
- 閲覧履歴、閲覧中のWebページの内容、URL
- キー入力、マウス操作の内容
- 位置情報
- 認証情報、決済情報

## 2. 情報の利用目的

保存した情報は、以下の目的にのみ利用します。

- 作業時間の計測・記録・表示
- クライアント別・案件別の集計、統計の表示
- 利用者が設定した動作（休憩判定、自動停止、自動起動）の実行

## 3. 外部への送信・第三者提供

本拡張機能は **インターネットとの通信を一切行いません**。保存した情報が、開発者のサーバーや第三者に送信されることはありません。本拡張機能には独自のサーバー、アカウント機能、アクセス解析、広告は含まれていません。画面表示に使うフォントなども、すべて拡張機能の中に含まれています。

また、利用者の情報を販売・譲渡・第三者に提供することはありません。

## 4. 使用する権限について

本拡張機能は、以下の Chrome の権限を使用します。

| 権限 | 使用目的 |
|---|---|
| `storage` | 作業記録・クライアント・案件・設定をブラウザ内に保存するため |
| `idle` | パソコンの操作が一定時間ないことを検知し、休憩として計測を一時停止するため（操作の有無のみを判定し、操作内容は取得しません） |
| `alarms` | 操作がない状態が続いた場合に、計測を自動で終了するため |

## 5. データのバックアップと復元

設定画面の「バックアップ」機能を使うと、保存されているデータが JSON ファイルとして利用者のパソコンにダウンロードされます。このファイルの管理は利用者自身の責任で行ってください。

「データの復元」機能で読み込んだファイルは、利用者のブラウザ内でのみ処理され、外部に送信されることはありません。

## 6. データの削除

保存されたデータは、以下の方法でいつでも削除できます。

- 本拡張機能の画面から、個別の記録・案件・クライアントを削除する
- Chrome から本拡張機能を削除（アンインストール）する。この場合、本拡張機能が保存したすべてのデータが削除されます

## 7. Chrome ウェブストアのユーザーデータポリシーへの準拠

本拡張機能による情報の利用は、[Chrome ウェブストアのユーザーデータに関するポリシー](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq)（Limited Use の要件を含む）に準拠します。

本ポリシーの内容は、必要に応じて変更することがあります。変更した場合は、本ページにて最終更新日とともにお知らせします。
